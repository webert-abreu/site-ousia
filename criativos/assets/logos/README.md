# 🎨 Logos da Agência — Instruções de Uso

Cole os arquivos das suas logos nesta pasta (`criativos/assets/logos/`).

---

## 📌 Nomes Recomendados para os Arquivos

Para facilitar a integração automática com os templates e modelos de criativos, recomendamos salvar suas logos com os seguintes nomes:

- **`logo-principal.svg`** ou **`logo-principal.png`** (Logo completa com o nome da agência)
- **`logo-simbolo.svg`** ou **`logo-simbolo.png`** (Apenas o ícone/símbolo isolado da marca)
- **`logo-branca.png`** (Versão em branco transparente para fundos escuros)
- **`logo-cobre.png`** (Versão na cor acobreada da marca, se houver)

---

## 💡 Formatos Recomendados

- **SVG (Vetor):** Melhor opção para nitidez perfeita em qualquer resolução.
- **PNG Transparente:** Fundo transparente com resolução mínima de `500x500 px` ou `1000x1000 px`.
