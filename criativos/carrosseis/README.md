# 🎠 Conteúdos em Carrossel

Esta pasta é dedicada ao planejamento e criação de **carrosseis** (posts com múltiplos slides).

---

## 📐 Estrutura Típica de um Carrossel

1. **Slide 1 (Capa / Hook):** Título impactante com alto gancho de retenção.
2. **Slides 2 a N-1 (Conteúdo / Valor):** Desenvolvimento da mensagem em pílulas diretas e visuais.
3. **Slide Final (CTA / Fechamento):** Chamada para ação (Comentar, Salvar, Compartilhar, Seguir).

---

## 📂 Organização Recomendada

Para cada carrossel criado, organize em uma subpasta:

```text
carrosseis/
├── modelo-base.html                     # Visualizador e estrutura base de slides
└── 2026-08-carrossel-arquitetura-brand/ # Exemplo de carrossel
    ├── slide-1.png
    ├── slide-2.png
    ├── slide-3.png
    ├── slide-4.png
    ├── slide-5.png
    └── legenda.txt
```

---

💡 *O arquivo `modelo-base.html` inclui uma pré-visualização de carrossel de 5 slides com navegação baseada no design system da Ousia Studio.*
