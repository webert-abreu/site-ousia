# 📸 Capas de Destaques para Instagram — Ousia Studio

Esta pasta contém as 3 capas de destaques do Instagram projetadas sob a identidade visual da **Ousia Studio** (Marrom Ébano `#14100E`, Cobre `#C28E68`, Creme `#F5F0EB`, tipografias *Cormorant Garamond* + *Tenor Sans* + *Space Mono*).

---

## ⚡ Como Visualizar e Baixar em PNG

Abra o arquivo [`index.html`](file:///c:/Users/werbe/Desktop/site-ousia/criativos/destaques/index.html) no seu navegador para acessar a **Central de Capas de Destaques**. Nela você pode:
- Alternar entre a visualização individual e em grade.
- Baixar o PNG de alta resolução (`1080x1920 px`) de cada destaque com um clique.
